## 新增 app：BeyondCompare（Beyond Compare 5.2.5）

把 `C:\Users\xkyii\Downloads\Beyond Compare 5` 整合进仓库（用户提供的是官方 PA.c
BComparePortable 5.2.5 包，老式 Format 3.0 / PAL 2.x 结构）。

**发现与决策**
- 安全审计：所有 exe/dll 均为 Scooter Software 签名；`Patch.exe` 是 GnuWin32 的
  GNU `patch`（BC 自带，非破解工具）。`BC5Key.txt` 是网传「Beta / 9999 users」测试
  密钥 —— 用户选择原样保留（在 AppFile 内，不入库）。
- 用户选择：**双架构都保留**（64 位 `App/AppFile` ＋ 32 位 `App/AppFile32`）、
  **不迁移** Downloads 里那份跑过一次的 `Data/`（全新开始）。
- 命名：目录 `BeyondCompare`、AppId `BeyondComparePortable`、启动器
  `BeyondComparePortable.exe`（与原包 `BComparePortable` 不同，为对齐本仓库命名习惯）。
- launcher 去掉了上游的 `RunAsAdmin=force`（那只是为了让 BC 装 Explorer 外壳扩展，
  代价是每次启动弹 UAC）；副作用是右键菜单集成不可用，已在 help.html 说明。
- 数据重定向：`%APPDATA%\Scooter Software` ＋ `HKCU\Software\Scooter Software`
  （`[RegistryKeys]`）。`[DirectoriesMove]` 左键用 `AppDataScooterSoftware`。
- `.gitignore` 新增 `Apps/**/App/AppFile32`。

**踩坑（两个都很关键，已写回 skill）**
1. **ini 必须 CRLF**：用 Write 工具写的 ini 默认 LF，PA.c 工具用 Win32
   `GetPrivateProfileString` 解析 → LF-only 被当成一整行 → 键全读不到、
   Generator 报「appinfo 找不到」。DOpus 的 ini 全是 CRLF。
2. **Launcher Generator 只在 app 目录位于 `%TEMP%` 下才能工作**：任何其它绝对路径
   （工作区内 / `D:\Temp` / `C:\PA_Test` / 家目录 / 官方原包目录）一律失败，日志只留
   误导性的 `ERROR: [Details]:Name [Details]:AppID or [Version]:PackageVersion not
   found in appinfo.ini files`。已确认与沙箱无关（关掉沙箱同样失败）、与 appinfo 内容
   无关（同一份 appinfo 放 %TEMP% 下就能过）。**DOpus 等既有 app 现在同样失败**——
   是工具/环境层面的问题，不是本次改动引起的。
   → 已在 `Script/install.py` 的 `create_launcher()` 内置规避：把 `App/AppInfo` 暂存到
   `%TEMP%/PortableAppsLauncherBuild/<AppName>/` 编译，再把 `*Portable.exe` 拷回。
   实测通过，产出 `Apps/BeyondCompare/BeyondComparePortable.exe`（220,175 bytes，
   图标 16/32/48/256 已嵌入）。

**产出**
- `Apps/BeyondCompare/`：19 个配置/图标文件（入 git）＋ AppFile/AppFile32（gitignore）。
- git 干跑确认只收录 19 个配置文件，二进制全部排除。

`Apps/BeyondComparePortable_5.2.5.paf.exe` —— **27.0 MB，67 文件，压缩前 104 MB**，

**Installer 的两个坑（已写回 skill）**
1. **必须传 app 目录路径参数**：`PortableApps.comInstaller.exe "<APPS_DIR>\<AppName>"`。
   漏传 → rc=1、约 30s 退出、**完全不写日志**、不产 paf。注意它的日志目录
   `Installer\Data\` 下通常只有 `settings.ini`，这类失败根本不产生 log 文件。
2. **向导中途关闭会留下"残包"**：第一次构建时向导被提前结束，Installer 照样在
   `Apps/` 下留了个 7.1 MB 的 paf（真包 27 MB），且 `7z l` 报
   `Cannot open the file as archive`。**判定成功必须等进程退出且 rc=0**，
   再用 `<PAF_DIR>\PortableApps.comInstaller\App\7zip\7z.exe l <paf>` 校验内容清单，
   并比对"压缩前总字节 ≈ `App/` 目录实际体积"。正常耗时约 36s。

## paf 命名改为短名（同日 18:2x）—— 去掉 AppID 结尾的 Portable

用户提出：`.paf.exe` 后缀已表明是 Portable，文件名里再带一遍 `Portable` 冗余，
问能否把 `BeyondComparePortable_5.2.5.paf.exe` 改成 `BeyondCompare_5.2.5.paf.exe`。

**结论：能，但只能"构建后重命名"，配置层面无入口。**
- Installer 源码把名字硬编码为 `$APPID_$DISPLAYVERSION`（`InstallerWizard.nsi:744-782`），
  全文件再无第二个 FILENAME 赋值点，installer.ini 也没有覆盖键。
- AppID 不能动：PA.c 约定它必须是 `<Name>Portable`，且同时决定 launcher 文件名
  （`InstallerWizard.nsi:787` 要求 launcher ini 为 `App\AppInfo\Launcher\<AppID>.ini`）、
  `Data\settings\<AppID>Settings.ini`、Platform 应用标识与注册表键。
- 改名安全性：`PortableApps.comInstaller.nsi:440-455` 那个"末尾 15 字符须为
  `_online.paf.exe`"的自检，整段被 `!ifdef DownloadURL` 条件编译包裹 —— 只有
  installer.ini 设了 `[DownloadFiles] DownloadURL` 才有。本仓库不填下载源 → 零风险。

**实现**（`Script/install.py`）：
- 新增 `read_appid(app_name)`（configparser，`interpolation=None`，键名大小写不敏感）
  与 `rename_paf(app_name)`（把 `Apps/<AppID>_*.paf.exe` 改名为
  `<AppID 去尾部 Portable>_*.paf.exe`，目标已存在则覆盖，幂等）。
- `create_installer()` 在 Installer 退出后自动调用；新增 `--rename-paf`（只改名不构建）
  与 `--keep-portable`（恢复原生命名）两个开关。
- 实测：12 个 app 的 AppId 全部以 `Portable` 结尾，规则可统一适用。注意
  `Apps/XShellPlus` 的 AppId 是 `XShellPortable` → 安装包会叫 `XShell_8.0.0.9.paf.exe`。
- 已把现存 4 个 paf 一起改名：`BeyondCompare_5.2.5` / `DirectoryOpus_13.24` /
  `FlyingBird_3.1.8` / `RapidEE_3.9.0`。改名后 `BeyondCompare_5.2.5.paf.exe`
  7z 复验仍为 67 文件 / 压缩前 109,235,650 字节，完好。
- 顺带在 `.gitignore` 补了 `__pycache__/` 与 `*.pyc`（py_compile 会生成）。
