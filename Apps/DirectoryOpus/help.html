Directory Opus Portable Help

Directory Opus Portable is a highly configurable file manager, packaged with a PortableApps.com launcher so you can carry it on a USB drive or cloud folder and run it on any Windows PC without installing.

Homepage: GPSoftware

This is a personal portable package. Directory Opus is proprietary software; make sure you have a valid licence for the machines you use it on.

Portable Notes

  • Your configuration and licence state (the HKCU\Software\GPSoftware registry branch and the three GPSoftware data directories under AppData / LocalAppData / ProgramData) are stored under Data\ and travel with the app.
  • The licence certificate is carried as dopus.cert inside Data\ProgramDataGPSoftware\Directory Opus\. Once you have installed your certificate on any machine, it is saved back into Data on exit and restored automatically on every other machine — no re-import needed.
  • If you already have a machine with Directory Opus activated, you can simply copy its %PROGRAMDATA%\GPSoftware\Directory Opus\dopus.cert into Data\ProgramDataGPSoftware\Directory Opus\ to activate every portable copy without using the Licence Manager at all.
  • Explorer shell integration (right-click menu, file type associations) is machine-level and is not portable; it will not be available on other machines. Directory Opus itself runs fine without it.
  • On first run, configure Directory Opus to your liking, then exit normally so the launcher writes your settings back into Data\.
