FlyingBird Portable

FlyingBird Portable is a personal, portable packaging of the FlyingBird proxy/VPN client for use with the PortableApps.com Platform. Your configuration, profiles and caches are stored alongside the app in its Data directory, so the whole package can be moved between machines on a USB drive.

Usage

Launch FlyingBirdPortable.exe from the PortableApps.com Platform (or directly). On first run, the app's %APPDATA%\FlyingBird\FlyingBird and %LOCALAPPDATA%\FlyingBird\FlyingBird directories are redirected into the portable Data directory.

Helper Service (TUN mode)

FlyingBird ships a FlyingBirdHelperService.exe used by some features (e.g. TUN mode). This portable launcher does not install it as a system service; those features may require administrator elevation and are not guaranteed to work portably.
