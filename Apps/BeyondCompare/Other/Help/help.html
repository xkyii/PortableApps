Beyond Compare Portable Help

Beyond Compare Portable is a file and folder compare, merge and synchronize tool, packaged with a PortableApps.com launcher so you can carry it on a USB drive or cloud folder and run it on any Windows PC without installing.

Homepage: Scooter Software

This is a personal portable package. Beyond Compare is proprietary software; make sure you have a valid licence for the machines you use it on.

Portable Notes

  • Both the 64-bit and 32-bit builds are included (App\AppFile and App\AppFile32). The launcher picks the right one for the host OS automatically.
  • Registration travels with the app. Beyond Compare reads BC5Key.txt from the folder that holds BCompare.exe, so the key file inside App\AppFile is picked up automatically — no re-registration on a new machine.
  • Your settings (the %APPDATA%\Scooter Software directory and the HKCU\Software\Scooter Software registry branch) are stored under Data\ and travel with the app. On first run, configure Beyond Compare to your liking, then exit normally so the launcher writes everything back into Data\.
  • Explorer shell integration (right-click compare menu, BCShellEx) is machine-level and is not portable — it is not registered by this package, which keeps launching UAC-free. Beyond Compare itself runs fine without it.
  • Do not use Beyond Compare's built-in updater — it would install a per-machine copy. To upgrade, replace the files in App\AppFile (and App\AppFile32) with the new build and update App\AppInfo\appinfo.ini.
